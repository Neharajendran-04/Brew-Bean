Brew & Bean 

Brew & Bean is a responsive coffee shop website developed as a frontend project using HTML5, CSS3, and Tailwind CSS.

The website features a modern coffee shop layout with sections for the menu, story, coffee roast collection, testimonials, and contact information. The design focuses on responsive layouts, typography, color combinations, spacing, and a consistent visual style across different screen sizes.

Technologies Used :
HTML5
CSS3
Tailwind CSS
